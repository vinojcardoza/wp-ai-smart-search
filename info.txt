short / typo	7	Very short queries and misspellings	“postgress vs mongo which db shud i use”
out_of_domain	3	Nothing in the posts answers it	“best recipe for sourdough bread”
“Can my website keep working when the user goes offline?” The progressive web apps post contains the word “offline”, but meaning-only search missed it. Adding keyword search (hybrid search) should catch this.

“following one request as it hops across many services…” The observability post on tracing didn’t come up.
